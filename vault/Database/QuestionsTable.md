# Database Table: Questions

## Overview
Stores the primary question metadata and body text. Includes unique constraints and foreign keys to categorizations.

## Schema Definition

```sql
CREATE TABLE "Questions" (
    "Id" integer GENERATED BY DEFAULT AS IDENTITY,
    "ExternalId" text NULL,
    "Title" text NULL,
    "QuestionText" text NOT NULL,
    "Difficulty" integer NOT NULL,
    "CategoryId" integer NOT NULL,
    "Status" integer NOT NULL DEFAULT 1,
    "IsDeleted" boolean NOT NULL DEFAULT FALSE,
    "DeletedAt" timestamp with time zone NULL,
    "CreatedAt" timestamp with time zone NOT NULL,
    "UpdatedAt" timestamp with time zone NULL,
    "CreatedByUserId" text NULL,
    CONSTRAINT "PK_Questions" PRIMARY KEY ("Id"),
    CONSTRAINT "FK_Questions_Categories_CategoryId" FOREIGN KEY ("CategoryId") 
        REFERENCES "Categories" ("Id") ON DELETE RESTRICT
);
```

## Indexes
* **PK_Questions**: Primary key index on `Id`.
* **IX_Questions_CategoryId**: Foreign key index for category trees.
* **IX_Questions_ExternalId**: Unique index for upserts and imports:
  ```sql
  CREATE UNIQUE INDEX "IX_Questions_ExternalId" ON "Questions" ("ExternalId") 
  WHERE "ExternalId" IS NOT NULL;
  ```
